# LSTM-ARO 論文互動網站

這個網站以互動式投影片介紹 Burak Gülmez 的論文 *Stock price prediction with optimized deep LSTM network with artificial rabbits optimization algorithm*。內容涵蓋 LSTM 股價預測模型、人工兔子最佳化演算法（ARO）、超參數搜尋，以及論文中的模型比較與實驗結果。

網站保留原簡報的 39 張投影片，並加入公式與模型架構的互動拆解、可調整參數的圖表，以及論文結果數據，方便逐步理解 LSTM-ARO 的方法與表現。

論文來源：Gülmez, B. (2023), *Expert Systems With Applications*, 227, 120346，[DOI: 10.1016/j.eswa.2023.120346](https://doi.org/10.1016/j.eswa.2023.120346)。倉庫中的[原始論文 PDF](1-s2.0-S0957417423008485-main.pdf)未經修改，依論文標示的 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 授權分享。
